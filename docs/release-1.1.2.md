# ZzzHe TMA Analysis 1.1.2

本版继续改善速度与连续操作的稳定性。

- 图窗切换只刷新一次所选曲线及图形，取消已经被完整重绘覆盖的尺寸调整任务。连续收到相同尺寸的通知不会重复重建图形；真正改变窗口大小时仍会重新布局。
- 坐标轴布局和结果标注复用同一次渲染得到的尺寸信息。带测量标注的绘图减少一次完整绘制，保留独立文字拖动、显隐、字号和导出效果。
- 文件框排序、筛选使用单个后台线程，最多保留一个最新待执行请求。连续点击表头不再无限创建线程；过期任务可取消，迟到结果不会覆盖新排序或新目录。关闭文件框不等待排序结束，后台不持有 Qt 控件。
- 关闭图窗时同步释放其隐藏的导航工具栏并取消排队重绘，避免旧工具栏继续持有画布，以及迟到重绘访问已删除画布。
- 设置读取与保存的后台任务即使发生未预料的普通异常，也会返回错误消息，退出加载/保存状态。无效的路径、界面和 m 缓存配置结构会被明确提示，不交给控件造成崩溃，不覆盖原配置。

同机、相同两份实验文件各打开四次的源码基准：切换 8 张图的绘制次数由 40 次降至 24 次，耗时约由 1.6 秒降至 1.0 秒。五次带标注重绘由 15 次完整绘制降至 10 次。数字用于比较本机测试，不代表网络文件读取时间或所有电脑的保证。

数据、计算公式、导出分辨率和现有功能保持原有设定。成就继续只尝试 C 盘配置目录，保留原有统计。完整解压后运行主程序，请保留整个依赖文件夹。沿用 ZzzHe 本地作者签名及时间戳，自签名不代表 Windows 公开信任。

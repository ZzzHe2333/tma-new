# ZzzHe TMA Analysis 1.1.26

- PNG/TIFF 导出和分享图加入 DCT 频域来源标记、元数据完整性记录及导出日期。
- 工具 → 图片鉴定：新的结果卡片和通过徽章；显示图片路径、整个文件的 SHA-256、日期、时间、时区、版本和免责声明。后台读取同一快照进行鉴定和哈希计算。
- 设置 → 界面缩放：全部放大、图标放大各可选 1×、1.25×、1.5×；图标使用两者中较大的倍率，重启生效。
- 设置 → 界面颜色：淡蓝、淡粉、淡黄、浅灰、淡红，实时切换并后台保存。

频域标记仅用于来源辅助判断，不保证裁剪、缩放、强压缩后仍可识别。内置来源标记不能充当第三方防伪认证。旧版本图片可能没有标记。

完整解压后运行 ZzzHe TMA Analysis.exe。沿用现有本地 ZzzHe 作者签名，不修改系统信任设置。

# ZzzHe TMA Analysis 1.0.2

作者：ZzzHe。发布日期：2026-10-24。

数据导入选择框改为程序内的详细列表，显示名称、大小、类型和修改时间，默认按真实修改时间降序排列，最新文件在前。可点击列标题手动调整排序；下次打开选择框时仍默认最新在前。此排序只作用于本应用的选择框，不更改 Windows 资源管理器的文件夹设置。

每次启动后，第一次选取数据从设置的默认打开文件夹 A 开始。若选择了 B 中的文件，本次运行后续从 B 开始；主界面导入、批量导入、单样品报告中的 TMA 选择及打开分析文件共享这份临时记忆。仅浏览其他目录后取消不会改变记忆。重启后重新从 A 开始。

设置中的默认目录不会被 B 覆盖。粒径目录仍使用自己的独立配置，图片／表格输出目录也不替代数据导入目录。

保留 1.0.1 的直接关闭行为及其他已实现功能。完整解压 ZIP 后运行 EXE，保留 `_internal` 依赖目录；沿用 ZzzHe 自签名证书与时间戳。

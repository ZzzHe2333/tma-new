# ZzzHe TMA Analysis 1.1.16

批量导入入口只整理文件路径文本，真实路径和共享目录的访问由后台计算任务处理。某个文件的路径响应慢时，界面仍能显示任务并接受后续追加；重复导入的行继续保持独立。

后台在解析路径、读取原始数据、解码和计算阶段之间检查取消标记。系统中已经开始的 I/O 仍可能需要等待返回；返回后会跳过尚未开始的后续阶段。已取消任务的结果不再更新表格。

复制提示修正为与实际结果一致的五列：文件名（不含扩展名）、T1、T2、M、H。保留数值算法、导出形式和已有称量配置规则。

使用真实样品和模拟的慢路径验证多文件导入、追加、取消后停止读取、再次处理、复制顺序和源文件不变。测试不代表所有网络共享环境均已验证。

# ZzzHe TMA Analysis 1.1.3

本版优化文件读取和曲线运算底层，保留原有界面及计算方法。

- 单调升温、降温或含保温段的局部平滑/求导，采用向前推进的物理窗口边界，避免每个点重复扫描大窗口。最少五点的扩展方式、端点和浮点边界比较、最小二乘输入与运算顺序保持一致；温度反转时继续使用原先的逐点邻域搜索，不排序或拼接采集分支。
- 大份 StartOfData 文本批量转换与校验。格式异常、缺列、多列、非有限数值等仍回到严格的逐行解析，保留完整前缀和具体错误行提示。保留 D 指数、历史编辑 .007、缺失尾部信号定义及多种文本编码支持。
- 常规 X 轴和未平滑的自定义 X 信号直接读取所需列，不再反复构建全长行号和缓存键、复制整张多通道表。返回数组仍独立；平滑和求导缓存继续区分所选数据、信号类型和物理宽度。
- 原始文件缓存的独立数组复制移到全局缓存锁之外；一个大文件复制较慢时，其它文件读取可以继续。每次打开仍得到独立数据和元信息，缓存不会暴露给编辑操作。

同机合成数据基准（不代表整套软件或所有文件的加速倍数）：

| 工作负载 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 6,000 点、120 ℃ 窗口的一阶导数 | 约 3.40 秒 | 约 0.29 秒 |
| 100,000 行、五通道文本解析 | 约 0.51 秒 | 约 0.18 秒 |
| 100,000 点自定义普通 X 信号连续读取 30 次 | 约 0.22 秒 | 约 0.04 秒 |

文本工作负载的 Python 分配峰值约从 44.9 MB 降到 27.6 MB。基准中所有结果与 1.1.2 保存的数组逐元素核对一致；另有浮点位模式、反转、保温、边界、损坏文本、单位和数据缺口测试。实际实验文件保持只读。用户提供的批量 T1/T2/H 检测算法未修改。

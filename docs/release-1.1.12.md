# ZzzHe TMA Analysis 1.1.12

点击“设置 → 通知”时先输入原来的通知密码。密码正确后才会读取并展示通知设置；保存不再重复询问。关闭窗口后再次打开，需要重新验证。密码错误的退避限制继续生效。

通知使用当前电脑的 Windows 标识和网卡标识生成机器码，并先校验本地缓存。发现缓存属于其他电脑时，丢弃旧机器码及地址信息，重新获取；同一电脑有效期内继续复用地址缓存。通知格式的示例明确标注为示例。

新版通知机器码会重新生成一次。更换网卡或重新安装系统可能改变该机器码。会员授权逻辑不受影响。

保留批量复制“文件名（无扩展名）、T1、T2、M、H”五列。完整解压软件包后启动主程序。

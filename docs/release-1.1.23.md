# ZzzHe TMA Analysis 1.1.23

分享预览直接生成 PNG 字节，省去临时图片写入和原始文件真实路径检查。慢共享盘上的源文件不再因为这一步路径检查拖住分享预览；图片保持与原导出一致的分辨率、标题、批注、白边和 Power By ZzzHe 作者信息。普通导出的原始数据保护继续保留。

分享窗口的初次配置加载，以及点击“分享图片”后的配置核对改为后台任务。配置未就绪时显示准备状态；连续点击不会重复排队发送。发送前重新读取配置，使用当时的云盘及企业微信设置。

准备阶段可以关闭分享窗口或退出主程序；取消后的旧配置结果不会重新打开窗口或触发发送。网络发送已经开始时，分享窗口继续显示发送状态；主程序仍可直接退出。

实际分享配置读取最多同时两个。已有读取长时间未返回时，新的请求及时提示稍后重试，避免重复开关窗口积累大量正在读取配置的任务。GUI 回调只处理内存数据，PNG 绘制继续在界面线程进行。

验证包含阻塞配置读取时的界面心跳、取消及主窗口退出后的延迟结果隔离、重复点击、最新配置核对、输出图片一致性和原始样品哈希。本机 WebDAV 测试服务器用于核对实际上传；企业微信请求通过模拟传输核对，没有向真实群聊发送消息。测试不代表全部网盘或物理网络环境。

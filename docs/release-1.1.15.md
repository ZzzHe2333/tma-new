# ZzzHe TMA Analysis 1.1.15

修复并发保存不同设置时，两次操作都显示成功、其中一项却被旧配置覆盖的问题。数据路径、批量窗口、重量缓存、粒径目录、通知、分享、云盘、MCP 和打印设置都使用协调的读取、修改、写入流程，只更新各自负责的部分。

多个本版本程序实例使用同一配置时也会协调保存。后台保存可以等待正在进行的更新，界面缓存读取继续可用；同步保存入口遇到繁忙配置时及时说明尚未保存，保留窗口内容，待前一项完成后可重试。

“留空保留”通知地址和分享地址以实际保存时的最新内容为准。用户目录不能写入时继续使用原有备用配置机制；失败不会发布未落盘的缓存。配置不同的实例不会相互阻塞，退出的进程不会永久占用保存权限。

验证使用隔离配置和受控的写入延迟，包括同一进程、多进程、备用路径、失败重试和界面心跳。原始仪器数据和计算公式未修改。

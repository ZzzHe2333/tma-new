# ZzzHe TMA Analysis 1.1.21

批量入口优先使用已经加载的 m 路径，不再在界面线程读取配置。首次配置尚未读取完成时，先计算并显示 T1、T2、H，再在后台读取 m 路径并匹配重量。已知来源的批次保留各自的路径，期间修改设置不会让新旧批次串用重量表。配置读取失败时保留数值，M 留空并给出原因。

配置尚未就绪时，自动弹出批量窗口和通知均延后处理。已配置不弹窗时不会先显示再隐藏；用户已关闭的批量窗口不会被较晚返回的设置重新打开。通知等待队列最多保留 64 条及 1 MiB 文字，关闭应用时清空，不阻塞退出。

在 m 配置尚未确认时，可以复制结果、出图以及导出到新文件。为保护尚未识别的称量表，这段时间拒绝覆盖已有文件，改用新文件名即可。该限制在发布文件的最后一步执行，避免目标文件在检查后被其他程序创建时遭到覆盖。m 来源确认后继续使用原有的覆盖及原始数据保护规则。

通知图片直接在内存中生成，保留原有白边、标题及 Power By ZzzHe 信息，减少临时文件和原始路径检查。导入通知在新文件完成绘图后才取图，修复可能附上上一张图的问题。延迟通知关联原图窗；等待期间原图窗已关闭或曲线重绘时，仅保留文字，不使用其他文件的图像。

隔离检查覆盖慢配置下的多文件导入、数值显示、五列复制、新 XLSX 和 PNG 导出、已有称量表保护、取消、延迟弹窗、来源切换，以及通知的容量和取图行为。没有发送真实通知或改写原始测试文件。T1/T2/H 算法及 XLSX 四个数值列保持原样。

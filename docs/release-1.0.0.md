# ZzzHe TMA Analysis 1.0.0

作者：ZzzHe。发布日期：2026-10-24。

本版将截至 0.37.7 的已实现功能定版为 1.0.0。采用 Python 后端、Qt 桌面界面，保留多窗口绘图与统一的浅色主题。

## 安装与启动

1. 将 ZIP 完整解压到本地文件夹。
2. 打开 `ZzzHe TMA Analysis/ZzzHe TMA Analysis.exe`。请保留同目录的 `_internal` 等依赖文件，不能只复制一个 EXE。
3. 使用“文件 → 打开”或拖入数据文件。需要教程时，打开“帮助 → 帮助主题”，或按 F1。

发布包已包含运行环境，无需另外安装 Python。首次启动会建立字体缓存，之后优先复用。

## 已实现的主要功能

- 读取已验证的 TA TMA 数字后缀数据与 StartOfData 文本，包括测试集中的历史手工编辑 `.007` 文件；保留全部原始列，未知尾列显示为未命名信号。
- 独立打开多个文件，同一文件可重复打开；多窗口单图与叠图，手动／自动配置叠图、独立结果文字及坐标刻度调整。
- 右键选点、精确输入界限、确定／取消，尺寸变化、信号变化、高度差、信号最大，以及当前支持的斜率、Alpha、转变和峰分析。
- 区间面积与公式说明，支持四种基线、实际时间或当前 X 积分，正／负／净／绝对面积；保留已实现的线性与水平 S 形峰积分和运行积分。
- 批量提取 T1、T2、M、H，查看与筛选本次应用运行内的批次，导出图片、XLSX 或复制表格。
- 配置称量数据路径与缓存、默认导入文件夹、粒径目录；匹配 m 后可在叠图中逐条确认质量并统一到 0.50 mg。
- 单样品 PDF 报告、可选模板及既有兜底方式；图片导出、白边、分享、A4 打印设置与预览。
- WebDAV 文件与本地缓存、可选 MCP 服务、界面大小设置、文件信息编辑、会话保存及可搜索的离线操作教学。

## 配置与保存

设置位于 `%LOCALAPPDATA%/ZzzHeTMA`。若该目录不可写，程序会按既有规则尝试便携配置位置，设置窗口显示实际配置文件；配置标识与之前版本保持兼容。升级时请保留已有配置。

分析和文件信息的编辑可通过“文件 → 保存会话”或“保存分析 → 分析和数据”保存为 `.tmas`。原始实验文件保持只读。批量批次仅在本次运行内保留，需要长期保存时请导出结果表格。

发布包不包含个人设置、称量表缓存、账户激活信息、运行日志或私钥。

## 签名与适用范围

EXE 使用署名为 **ZzzHe** 的既有 Authenticode 自签名证书和 RFC3161 时间戳；包内 `ZzzHe-Publisher.cer` 仅含公钥。数字签名属性可查看作者，启动程序不会自动安装根证书或更改系统信任设置。该签名不代表 Windows 公开信任或 SmartScreen 免提示。

1.0.0 表示当前产品功能定版，不表示已完整复刻原 Universal Analysis。尚未实现的项目继续灰显；专用 DSC/TGA/DMA 分析、旧宏兼容及未实现的峰拆分方法不在本版范围内。TMA 面积不直接解释为焓或结晶度。

`power` 保留用户提供的算法脚本；`T1-T2-H/extract_t1_t2_h.py` 是可独立复制使用的提取脚本，其独立运行仍需 Python 和 NumPy。

# ZzzHe TMA Analysis 1.1.25

- 内部识别实验编号、重复测试、A/B 料生产编号和 W456 外来样品。
- 导出图像外围色框：实验淡粉、生产淡橙、外来浅绿；未知、冲突或混合类别浅灰。
- 点击图表左上样品名，在显示与条形码隐藏之间切换。
- 点击右上来源，在完整路径、隐藏路径保留文件名、全部隐藏之间循环。
- 隐藏采用 Code 39 条形码，编码内容为 `ZZZTMA POWERBYZZZHE.`。
- 导出、复制和分享图片使用当前隐藏状态；原始文件和样品元数据不变。隐藏状态属于当前图表，重新启动不保留。

完整解压后运行 `ZzzHe TMA Analysis.exe`。沿用现有 ZzzHe 本地作者签名，不修改系统证书信任设置。

# ZzzHe TMA Analysis 1.1.20

主窗口创建之后，自动启动 MCP 所需的配置读取转到后台，配置完成后再处理登录通知及已配置的云缓存维护。云缓存维护是否启用的检查也放在后台，不再在界面线程读取配置。MCP 仍默认关闭，仅按保存的设置启动。

字号菜单先使用本次已生效的字号，后台核对保存值；用户已经发起新的字号选择时，较晚返回的初始读取不能覆盖新选择。实际界面缩放仍在程序启动前确定，保存字号后需要重启。

后台读取期间重复请求重载 MCP 会合并处理。读取期间手动关闭服务、保存新的关闭设置或退出程序后，旧结果不能再次启动服务。云缓存维护执行期间新增的计划任务请求会合并保留，退出后尚未执行的清理及注册操作会跳过。

这些后台任务只持有普通数据，结果由界面定时接收；后台线程不持有或调用 Qt 对象。取消任务后，窗口及任务对象可在后台读取仍未返回时释放，退出不等待读取完成。

验证覆盖慢配置读取下的界面心跳、冷配置下的窗口创建、退出响应、旧结果隔离、字号选择保留及后台对象释放。另保留本地 MCP 客户端往返、WebDAV 本地测试服务和原有数据处理流程的检查。没有发送真实通知、操作真实云端文件或在测试中注册系统清理任务。

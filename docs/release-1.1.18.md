# ZzzHe TMA Analysis 1.1.18

通知关闭时，主窗口的首次事件处理不再加载 HTTP 网络库。通知配置读取和企业微信地址校验也不加载该库；实际发送时才在后台任务中加载。分享发送按需加载相同依赖，现有超时、地址校验和错误提示保留。

保留通知设置入口的密码验证：密码正确后才读取和展示通知配置，取消或密码错误不会打开设置，关闭后重新打开仍须验证。通知机器码由当前电脑的信息生成；使用地址缓存前先核对当前机器身份，发现换机时清除旧电脑信息，避免随软件包复制而沿用。

本机源码重复启动测量中，优化前首次事件处理约 0.47 秒，优化后约 0.03 秒。此数据仅说明该启动阶段的变化，实际电脑和 EXE 的总启动时间受磁盘缓存、安全软件及配置影响。

隔离检查覆盖通知默认关闭、配置校验、首次网络库加载被阻塞时的界面响应，以及模拟请求的发送、超时和重定向策略。通知服务请求使用本地模拟，不向真实渠道发送。换机识别使用模拟硬件和复制缓存检查，未在第二台物理电脑上验证。

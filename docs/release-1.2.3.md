# ZzzHe TMA Analysis 1.2.3

- 单样品报告可以查看 P9M 中的全部记录，区分名称匹配、系统默认和当前选择，也可以手动选用其他记录。换样品时会刷新 PDF 文件名，报告窗口底部可手动刷新 M 缓存。
- 统一化叠图保留温度标记，按质量比例换算 H。标签可拖动，复制叠图后可分别调整位置。
- 「设置 → 显隐功能」可选择工具栏和图表右键菜单中的命令。「设置 → 设置备份」支持本地文件和 WebDAV。
- 修复直接批量出图时中文可能显示为方框、关闭叠图后残留标记，以及切换界面倍率后已隐藏按钮重新出现的问题。
- 生成报告时会检查源文件是否在读取期间发生变化，并提示重新读取。

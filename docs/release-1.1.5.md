# ZzzHe TMA Analysis 1.1.5

本版减少多文件导入时的空白绘制，以及坐标和图例的重复工作，保留原有算法与界面布局。

- 尚未查看的文件图窗不再因尺寸事件创建空白 Agg 图像缓冲。第一次切换到该文件时正常绘制；显式绘制、导出、打印和关闭功能保留。
- 坐标输出复用自己独占的中间数组，避免重复复制原始 Y 信号与多次标量变换临时数组。计算顺序和浮点舍入保持一致，返回数组仍独立、可写；不修改原始数据、处理曲线或 X 缓存。直接 API 调用使用 NumPy 等特殊标量时，保留原先的类型提升方式。
- 完整连续曲线绘制时不再创建全长采样行号，也不复制两份没有缺口的曲线以插入空的 NaN 列表。有排除区间的曲线继续按原位置插入断线，不连接数据缺口。
- 同一个图例绘制过程内复用重复的位置搜索结果，结束即清空；每帧、缩放、字体、手动位置或导出渲染器发生变化时，仍执行新的位置搜索。不减少采样点，也不近似寻找位置。

同机、同一离屏 Qt 进程中交替执行九轮八文件真实数据导入，仅切换空白画布绘制策略，得到：

| 指标 | 原策略 | 延迟策略 |
| --- | ---: | ---: |
| 导入中位时间 | 约 305 ms | 约 248 ms |
| 未查看图窗的空白绘制 | 7 次 | 0 次 |
| 已分配绘图缓冲的图窗 | 8 个 | 1 个 |
| 图像缓冲合计 | 约 17.0 MB | 约 4.7 MB |

这些内存数值只统计绘图缓冲，未统计软件其它内存；已查看的图窗会正常分配自己的缓冲。10 万点普通坐标输出测试的 Python/NumPy 分配峰值约从 4.8 MB 降至 4.0 MB。图例位置搜索由每次绘制两次降为一次；八曲线、80 万点叠图以及多个分辨率下的图像逐像素一致，坐标、单位、数据缺口和处理结果精确对照一致。耗时会随机器和其它负载变化，不将局部收益视为整套软件统一加速。

完整解压后运行主程序，保留全部依赖。沿用 ZzzHe 作者自签名与时间戳；自签名不代表 Windows 公开信任。原始实验文件、用户算法、个人配置和旧版安装包不被覆盖。

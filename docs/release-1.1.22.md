# ZzzHe TMA Analysis 1.1.22

文件选择框读取目录时改用独立进程。取消、切换目录或关闭主窗口时，可以终止正在等待的读取进程，减少旧的慢目录占满后台名额后，其他本地目录也无法打开的情况。目录读取全程不在界面线程进行。

每个文件选择框只有一个协调线程，连续切换目录时保留最后一个待执行请求；程序最多同时运行四个目录读取进程。无进展持续 30 秒时显示超时，可刷新或切换路径；持续返回条目的大目录不受总时长 30 秒限制。Windows 使用 Job Object 管理已启动的读取进程，主进程结束时回收子进程。若系统尚未确认某个进程退出，其名额仍被保留，避免重复增加未结束的进程。

仍按修改时间从新到旧显示，保留目录导航、筛选、中文文件名和 `.007` 文件。读取进程只读取所选目录；临时结果保存在独立的本地临时文件夹，结束后清理本次任务自己的文件，不修改源文件或递归清理用户目录。

打包后的目录读取进程也跳过绘图库启动时的临时配置创建，避免强制取消后留下绘图库临时文件夹。普通窗口启动继续沿用原来的绘图配置与缓存策略。

保留打开通知设置前的密码验证、换机机器码缓存核对，以及批量复制的“文件名（无后缀）、T1、T2、M、H”五列。

验证包含受控的慢读取子进程、四个同时等待的任务、连续切换、超时和关闭窗口后的资源释放，并检查实际 EXE 的本地目录加载。尚未在物理断开的共享盘及第二台电脑上复测，不将受控测试结果视为全部网络环境的保证。

# ZzzHe TMA Analysis 1.1.17

普通诊断事件由单独的后台线程写入，界面和数据任务不再等待日志的磁盘写入。事件内容在调用时形成快照，保留当时的线程标识和字段内容。

该队列只承载诊断事件，最多保留 2048 条、8 MiB 待写数据。极端积压时优先保留较新的事件，并在日志中写明丢弃数量。原有独立的原生崩溃堆栈日志继续启用。

正常退出时尝试排空事件队列，最长等待约 250 毫秒；日志写入持续阻塞或进程异常终止时，末尾尚未写入的普通事件可能来不及保存。采用原始文件描述符写入，避免后台写入未返回时在解释器退出阶段争用缓冲文件锁。

创建日志文件或启动日志线程失败时，会尝试清理本次创建的空文件并改用备用位置。各位置使用不同的文件名，即使空文件无法清理，收集日志时也不会覆盖成功的备用日志。正常事件顺序、并发写入、异常记录、队列溢出、独立崩溃堆栈，以及底层写入阻塞时的程序退出均有隔离测试。

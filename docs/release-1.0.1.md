# ZzzHe TMA Analysis 1.0.1

作者：ZzzHe。发布日期：2026-10-24。

点击主窗口右上角 × 直接退出，取消“保存当前会话”的退出询问。文件 → 退出及 Alt+F4 使用同一逻辑；标题栏不再显示未保存星号。

程序按数据读取与处理软件使用。图片、表格和分析文件均由用户按需导出或保存，不会在退出时自动保存当前数据。原“保存会话”入口改名为“保存分析文件”，已有 `.tmas` 格式继续兼容。

关闭时取消排队导入和后台任务，不等待慢文件或称量表读取，不因正在分享而弹窗阻止退出。未完成的导入、计算或发送可能随退出停止。已保存的文件及配置保留，原始实验数据保持只读。

完整解压 ZIP 后运行 `ZzzHe TMA Analysis.exe`，保留整个 `_internal` 依赖目录。沿用已有 ZzzHe 自签名及时间戳；其他已实现功能沿用 1.0.0。使用教程仍可通过 F1 打开。

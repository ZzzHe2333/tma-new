# ZzzHe TMA Analysis 1.1.19

通知开关和批量弹窗的界面检查优先复用已经加载的配置快照，避免每次导入、批量操作时重新遍历配置位置和读取 JSON。已加载配置时，即使后台刷新遇到慢磁盘，界面仍可使用上一次有效设置。

在本次程序里保存设置后，快照立即更新。对其他程序或手动修改的配置，在后续检查时按约 30 秒的间隔触发后台刷新；同一配置只有一个刷新任务，刷新失败也不会在每次操作时重试。较晚返回的旧读取不能覆盖本次新保存的设置。

设置窗口的显式读取、后台任务的读取，以及尚未加载过的配置首次读取仍保留原有行为；此版本优化的是已加载配置之后的高频界面检查。没有改动 T1、T2、M、H 算法、原始数据、通知权限或通知默认关闭规则。

隔离检查覆盖配置读取阻塞时的连续操作、界面心跳、外部改动刷新、本次保存立即生效、旧读取隔离，以及线程创建失败后的重试。通知发送测试使用本地模拟，不调用真实通知服务。

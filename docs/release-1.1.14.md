# ZzzHe TMA Analysis 1.1.14

叠图“添加曲线 → 打开文件”使用已有的后台导入机制；路径解析和文件读取不在界面线程进行。读取过程中可继续调整勾选或取消、关闭窗口。加载结束保留手动选择的信号和已有勾选项。

此入口也使用按修改时间降序排列的文件选择窗口，沿用设置中的默认目录和本次最近选定的目录；仍在手动叠图中默认推荐尺寸变化信号，新增文件继续由用户勾选。

关闭后返回的旧任务不再应用到窗口。后台解析路径结束时会检查取消标记，避免为已经取消的操作继续启动文件读取。系统中已开始的文件 I/O 可能仍需等待返回，但关闭窗口和后续操作不会等待它。

叠图候选列表继续跳过已列出的文件；主窗口正常导入仍允许独立重复打开。测试核对源文件未改变，并验证生成的叠图可以导出。

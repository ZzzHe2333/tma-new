# ZzzHe TMA Analysis 1.1.0

工具栏「成就」及「成就 → 成就展示墙」打开本地展示墙。新增 9 项微成就：成功出图、导入文件、新增并确定分析、创建叠图、处理批量样品、导出或复制表格、生成报告、成功分享、质量统一化。只计成功的对应操作；预览、取消、失败不计数。批量按成功样品/图片张数统计；重复打开文件计入导入次数。

每项都有木、石、铜、铁、金、钻石、下界合金 7 个等级，分别在 1、10、100、300、1,000、3,000、10,000 次获得。像素材质边框采用原创绘制，参考方块游戏的材质配色，保留应用的淡粉浅紫风格。已获得框凸起、未获得框凹入，悬停查看具体条件与获得时间。跨越多个等级时只弹最高新等级，全部框均会点亮；大批量时同项合并排队，避免弹窗刷屏。

达成时右下角显示小图标、成就标题和材质等级，带金币喷散动效，约 4.6 秒后消失，不抢焦点。统计仅保存到本机 `%LOCALAPPDATA%/ZzzHeTMA/achievements.json`，不可写时沿用配置的本地备用目录；后台读写，不连接外部服务，不记录样品名、路径或实验数据。重启保留，不回放历史弹窗。展示墙「清除统计」确认后清空次数、时间及成就框；不会清除设置、会员、实验数据或分析结果，之后可重新获得。

导入文件框改为后台枚举目录，不再调用 Windows 外壳获取文件图标或枚举全部驱动器。网络目录读取慢时，界面仍可输入路径、返回或取消；最多同时读取 4 个目录，迟到的目录结果不填入新目录。保留详情列表、真实修改时间降序、Ctrl/Shift 多选、文件类型筛选及本次 A/B 目录记忆。每次启动首次从设置默认目录进入，重启仍回到默认目录。

修复打开批注再次同步查称量表导致无响应：先复用当前曲线的 m，未就绪先填 0.50 mg；必要查询在后台进行，只有用户尚未编辑时才更新默认文字。手工修改后，迟到的重量结果不会覆盖文本。关闭批注取消等待，不阻塞界面或退出。

完整解压发布 ZIP 后运行 `ZzzHe TMA Analysis.exe`；无需安装 Python。沿用 ZzzHe 本地作者签名，不修改系统信任设置。

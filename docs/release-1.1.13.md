# ZzzHe TMA Analysis 1.1.13

通知最多同时使用两条后台线程。待发送和正在发送的任务合计最多 64 条，图片及事件、批次、路径文本的合计预算为 64 MiB；超过上限的新通知不会加入队列，通知错误状态会记录原因。已经接收的任务继续处理。此限制避免网络缓慢或不可用时不断创建线程、积压图片。

没有任务时自动退出通知线程，下次需要时重新创建；退出软件不等待通知任务。通知仍默认关闭。保留 1.1.12 的机器码校验和进入通知设置前的密码验证。

离线压力测试模拟连续触发 1000 次且发送阻塞，核对并发上限、界面心跳、接收任务无遗漏和空闲资源回收。测试不发送真实通知，不代表全部网络服务已经验证。

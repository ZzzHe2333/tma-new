# ZzzHe TMA Analysis 1.1.1

本版优先解决文件选择框、打开设置时的停顿。

- 文件选择前优先读取独立的内存配置快照，后台检查配置和旧版本备用位置，避免窗口出现前同步扫描。首次无快照时窗口仍可显示/取消；默认目录查到后，仅在用户尚未自行导航时应用。保存路径成功后更新内存，继续保留首次 A、本次 B、重启 A 的规则。
- 大目录使用按需取值的轻量表格模型，避免为每个单元格创建 Qt 项目。目录筛选和真实时间/名称/大小排序在后台完成；保留多选、选择状态、文件类型筛选和最新修改在前。迟到的排序结果不会覆盖新目录或新的排序要求。
- 设置窗口先显示已读配置，后台刷新。无配置快照时先显示窗口及加载提示，读取完成后才允许保存。后台返回不会覆盖已经编辑的路径，也不会打断称量测试。保存也在后台，保存失败保留表单并提示；仅保存成功后关闭和更新缓存。
- 成就统计优先写入 `%LOCALAPPDATA%/ZzzHeTMA/achievements.json`（正常 Windows 环境在 C 盘）；用户目录不可写时，改存 C 盘 `ProgramData/ZzzHeTMA/<配置标识>/achievements.json`。取消项目/发布目录回退写入；如果仅有旧备用统计，后台读取并迁移到 C 盘配置目录。原文件保留，C 盘统计存在后不再从旧项目统计恢复，清除后重启不会重新点亮旧成就。展示墙显示实际保存位置；两个 C 盘位置都不可写时明确提示，不改写项目目录或系统权限。

本机同一 10,000 条目录的源码操作基准：列表完整显示由约 1.69 秒降至约 0.29 秒，最长事件间隔由约 259 ms 降至约 68 ms。此数字是合成目录列表的界面基准，不包含网络传输时间，也不是所有机器的保证。目录响应慢时仍可关闭窗口或切换路径。

绘图数据、算法、导出分辨率与打印精度保持原有设置。保留完整解压后运行方式、ZzzHe 本地作者签名及旧版本。

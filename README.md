# ZzzHe TMA Analysis

基于 Python + PySide6（Qt）的独立热分析工作台。以本机 Universal Analysis 2000 v4.5 的功能资料为参考，优先实现 TMA 数据处理闭环；目前版本 **0.29.0**，并非原软件全部功能的等价替代。

0.29.0 统一更名为 **ZzzHe TMA Analysis**，采用奶油白、淡粉、浅紫与薄荷绿的可爱风格。菜单、工具栏、按钮、输入框、选项卡、表格与弹窗使用同一套主题，新增兔耳烧瓶应用图标及空白工作区。31 枚工具图标重新绘制，顺序不变；主窗口仍为 1400×900，工具按钮 24×24，工具栏高 26，常用弹窗尺寸与上一版一致。保留 MDI 多窗口及原有菜单结构；白色图纸、黑色曲线、坐标字体、独立标注与导出白边保持原样，页脚仍为 Power By ZzzHe。

已验证范围为现有 TMA 读取、绘图、叠图与分析操作；未实现的分析项仍灰显。图形外观调整不代表已完成原软件全部功能的等价复刻。已有会话与路径设置继续可用，原有绘图偏好配置位置保留以兼容旧设置。

## 路径设置与 m 重量

左上角「设置 → 数据路径」支持保存多个命名路径。配置文件为 `%LOCALAPPDATA%\ZzzHeTMA\settings.json`（本机位于 C 盘用户目录）。其中“默认打开文件夹”可指定桌面或其它目录，保存后导入文件、添加数据文件及打开会话都会以该目录作为起点，重启后仍有效；清空则使用系统默认位置。首项 `m` 可以选择 CSV、XLSX、XLS 文件，也可以选择包含这些表格的文件夹。新增路径目前用于保存其它数据源位置。

按当前样品名匹配表中样品名／批次号与 m／重量／质量列；无表头时沿用 B 列名称、C 列重量。保留原表数值及单位，未标明单位时不推定。可在设置中测试当前样品，保存后刷新已打开样品；缺失或冲突会显示原因。不会写入称量表或仪器文件；匹配记录随 TMA 会话保存。`TMA_MASS_XLSX` 环境变量保留为高级覆盖方式。

## 使用流程

1. 「文件 → 打开」或黄色文件夹按钮，导入一个/多个文件，每个文件打开独立绘图子窗。该对话框也能单独打开 `.tmas` 会话。拖放原始数据仍然可用。
2. 「曲线图 → 叠加 → 自动配置」打开文件/信号及自动样式设置窗口，沿用普通图的Y1–Y4分配，同单位可使用不同信号名称；不同单位需先分轴。线型、颜色、符号各自选择按轴或按曲线分配，读取叠图“自动”页十组序列，未勾选的自动样式沿用普通图。“手动设置”或“编辑”打开六页叠图选项，可添加、移除、排序/换轴。普通图与叠图分别保存线型、颜色、符号、线宽和Y偏移；叠图偏移叠加在普通图偏移上，第一条不增加。原始数组、处理记录及X平移/倍率仍由对应曲线共享。标题、图例和坐标范围按绘图窗口保存。
3. 右键曲线或使用「分析」菜单：「尺寸变化」显示两个控制点、T1/T2及有符号H；「高度差」默认只显示高度绝对值，原始有符号结果仍记录；「信号变化」同样提供两个控制点。「信号最大」默认落在全曲线实际最大值，图上只显示温度。左右拖动红十字，Y始终吸附曲线，选好后右键选「确定」或按Enter固定；右键「编辑…」输入精确坐标，「取消」放弃本次选点。此时普通右键菜单暂不显示。固定后可分别拖动温度/高度文字；需修改控制点时，右键「调整分析点」，重新选点后确定或取消。
4. 需要输入边界或批量分析时，在「分析 → 分析选项」的通用分析框中选择信号最大/信号变化，保留之前的区间计算方式。「峰最大」和「始点」已进入原生选点流程；Alpha有独立原生选项。「峰值积分 → 线性」直接图上选点并对记录时间积分；斜率和旧通用分析仍保留原对话框。CTE需填写**实测初始样品长度（mm）**。「工具 → 平滑」打开信号处理。「视图」查看结果、数据表、参数块和日志；「文件」保存会话、导出图像/数据。
5. 右键坐标数字／轴线或进入「重定刻度 → 手动重定刻度」输入范围和间隔。例如X起止50/300、标值50、刻度12.5；Y1起止-500/2500、标值500、刻度125。标值偏移仅把显示数字加上该偏移，不改变数据或分析温度；满刻度恢复自动范围与默认刻度。普通绘图与叠图各自保存坐标设置。

## 科学口径与数据范围

二进制读取器验证范围为 TA Q400、TMA Standard、五通道布局：UTF-16LE 头、`0c 00 05` 前导、little-endian float32 数组和结束标记。此布局之外的 TA 二进制不会被假定为同一格式。StartOfData 文本按 `Nsig / Sig1..N` 读取；文件扩展名不能证明数据格式。本机 `.005` 样本实际是文本。同名的 `.001`、`.005`、`.txt` 也可能包含不同处理结果，均独立读取。

原始文件仅以读取方式打开。输出操作阻止覆盖已加载源文件。正常结束记录与方法尾保留；截断或坏行会保留可信的完整数据前缀，并在界面与会话中记录警告，结果需结合警告判断。

旧通用分析**不排序或拼接采集分支，不插值区间端点**，仅计算边界内的实际样点。其斜率、峰值、积分、旧变化量、CTE、Onset要求严格单调 X；温度求导亦如此，有恒温段可切换时间域。新的信号最大与信号变化允许连续采集区间内的保温、温度回摆及升降温，记录实际采集方向；所有方法拒绝由 X 边界选出的不连续采集片段，需缩小区间或使用时间域。信号分析的全范围和图上取点保留精确采样 X，计算不受输入框显示精度影响。

- 斜率：最小二乘拟合，输出斜率、截距、R²。
- 峰值：所选区间的实际最大/最小采样点；不是自动寻峰或峰分离。
- 信号最大：所选连续采集区间内最大 Y，平局取最早采集点，记录该点 X/Y 及实际区间首末点；独立于「峰最大」保存结果类型。
- 信号变化：所选区间最后采集点 Y 减第一采集点 Y，记录实际起止 X/Y。降温仍按采集顺序保留正负；取消「有符号」仅令图中文字显示绝对值，底层结果始终保留符号。
- 交互两点分析：直接用两个控制点所对应的实际采样行计算 `H = Y2-Y1`，即使两点交叉，也保留控制点身份和差值符号。初始T1优先参考用户原脚本的超级梯度起点并吸附原始曲线，失败时取主峰之前的实际最小采样点；T2取实际最大值。控制点移动不执行排序、插值、平滑或温度warp。图中文字沿用用户脚本的显示规则：温度2位小数，|H|>1000显示整数，否则1位小数；底层结果保存完整精度。
- 积分：减去两端样点连线后沿采集方向梯形积分，单位为 Y 单位 × X 单位，降温面积保留方向符号；**不直接换算焓或结晶度**。
- CTE：`OLS slope [µm/°C] / 初始长度 [mm] × 1000`，输出 ppm/K。仅允许温度域、原始量纲为 µm 且未求导/归一化的信号。结果依据当前显示的 Y 倍率；人为倍率会改变 CTE。
- 旧通用 Onset：所选采集点前 20% 拟合基线，最大绝对斜率附近 20% 拟合切线，取交点。至少 10 点；平行或区间外交点拒绝。结果包含拟合窗口和 R²，需人工核对，不声称等同厂商算法。
- 平滑在采样点序号上进行；不是按温度重采样。处理作用于当前选中信号，随后应用显示平移/倍率/偏移。归一化为 `100 × y/y[0]`，首点为零时拒绝。分析使用显示变换后的数据，结果完整记录变换与处理参数。

## T1 / T2 / H 独立脚本

项目内运行 `python extract_t1_t2_h.py "测试文件\20261013-9#.001" --json result.json --csv result.csv`。

可复制单文件 `dist/T1-T2-H/extract_t1_t2_h.py` 到其它目录使用，只需要 Python 和 NumPy，不依赖Qt/Tkinter或本项目。参数：

```powershell
python extract_t1_t2_h.py "D:\data" --recursive --algorithm super --json results.json --csv results.csv --quiet
python extract_t1_t2_h.py "D:\data\sample.001" --plot-dir plots
```

`super` 为原超级梯度入口，`robust` 为原稳健/梯度入口。输出T1/T2（°C）、H1/H2/H（µm）、原曲线T1~T2积分（µm·°C）、源SHA256、算法来源SHA256、识别模式及警告。绘图选项额外需要Matplotlib，沿用原脚本的十字、两温度、水平参考线和高度箭头。

独立自动检测明确沿用原算法的温度排序、8位小数归并同温度均值、端点插值，与手动控制点的“实际采样行”口径不同。遇到明显降温回程会拒绝，需用 `--sample-start/--sample-stop` 指定单一升温段（0起算，起点含、终点不含）；保温小抖动保留。失败文件单独记录，不强行填数值。提取函数源码与原版AST逐项相同，来源记录在 `artifacts/point-verification/algorithm-provenance.json`。

## 0.24.0 水平 S 形峰积分

「分析 → 峰值积分 → 水平 S 形」现已接入实际计算、图上两点／四点界限、选点专用右键、精确编辑和自动界限。初始基线仍为当前X下的端点直线；随后按前次扣基线后的有符号累计面积分数，对起点／止点的两条水平线加权。每次重新对记录时间积分，面积相对前次变化不超过1%后接受，最多10次。未收敛时不会确认结果；自动界限提出的范围若不收敛，也不会覆盖原控制点和数值。

当前独立实现以**前次有符号总面积绝对值**作为相对变化分母，不裁剪累计分数；接近抵消零面积（128倍浮点epsilon×累计面积总变差）的情形报错。两端水平线完全相同或信号恰好等于初始基线时，无需反应分数迭代。以上分母、取消阈值及退化情形的精确厂商处理仍未运行核对，不能宣称数值完全等价。

「分析选项 → 其他」已启用「绘制S形基线迭代」，显示初始直线与中间迭代曲线；最后一条基线正常绘制。未收敛时也显示失败迭代供检查，最后一条用红色表示，但不会生成有效结果。保存／默认值仅作用本页，选项由新分析复制，旧结果保留各自显示快照。峰／始点文字、温度标签仍独立拖动。已经确认的直线和S形积分使用固定的结果快照；重新编辑控制点才重新计算，重绘和拖文字不会改动已确认数值。
